# @ui-call/preact

Idiomatic Preact binding for the core call store with seamless reactivity integration.

## ✨ Key Features

- 🌐 **Idiomatic Preact API** - Uses `useState` + `useEffect` for Reactivity binding
- ⚡ **Preact Signal** - Optional built-in `@preact/signal` integration

## 📦 Installation

```bash
npm install @ui-call/preact
```
